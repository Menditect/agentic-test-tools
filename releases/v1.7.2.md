# Menditect Agent Workspace Template - Release Notes

## Version v1.7.2

> Released on: 2026-09-24

### Release Summary
fixed error in mcp server verification

---

### Detailed Changes

- **Automatic MCP Handshake & Session Management**:
  - Fixed an issue where querying the MTA MCP server directly (e.g. during `npm run verify`) caused requests to hang or time out due to missing upstream session initialization.
  - `scripts/mta-proxy.js` now automatically initiates the standard MCP initialization handshake and captures the `mcp-session-id` header before forwarding downstream tool queries.
- **Improved MTA Service Account Authentication Diagnostics**:
  - Added pre-flight token length and format checks in `scripts/verify-setup.js`.
  - Added user-friendly error formatting in `scripts/mta-proxy.js` and `scripts/verify-setup.js` for upstream Mendix Cloud authorization errors.
- **Enhanced Setup UX & Configuration Flow**:
  - Replaced automatic printing of `mta_config.json` with an interactive prompt at the end of setup.
  - Added comprehensive next steps showing parameterized commands (`update:skills`, `update:mxcli`, `update:check`, `--yes`, `--force`) and how to run commands directly from workspace root using `npm run --prefix`.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
