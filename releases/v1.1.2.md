# Menditect Agent Workspace Template - Release Notes

## Version v1.1.2

> Released on: 2026-09-08

### Release Summary
Increased resilience of the local MCP proxy (scripts/mta-proxy.js) to transparently recover from Mendix runtime and Studio Pro restarts without requiring AI agents or IDE windows to be restarted. Added direct proxy support for the Studio Pro built-in MCP server, automatic background MCP session re-initialization, extended connection retry tolerance, and crash protection during offline states.

---

### Detailed Changes

#### 1. Self-Healing MCP Proxy Engine (scripts/mta-proxy.js)
- **Automatic Background Session Re-initialization**:
  - The proxy now intercepts HTTP 400/404 session errors and invalid session responses caused when upstream Mendix or Studio Pro processes restart and wipe their in-memory session tables.
  - Automatically executes the MCP `initialize` handshake in the background, extracts the new `mcp-session-id`, sends `notifications/initialized`, and transparently replays the agent's pending request.
  - Implemented request mutexing to prevent concurrent initialization storms when multiple tool calls arrive during a restart.
- **Direct Studio Pro Support (`studiopro` Mode)**:
  - Added support for running the proxy against the Mendix Studio Pro built-in MCP server (`node scripts/mta-proxy.js studiopro`, targeting `http://localhost:7782/mcp`).
  - Replaces previous reliance on raw `@modelcontextprotocol/server-sse`, which crashed whenever Studio Pro was closed or rebooted.
- **Crash Protection During Offline States**:
  - If Studio Pro or the local Mendix application is offline when the IDE or AI agent starts up, the proxy keeps the stdio communication channel open and returns a valid schema rather than terminating the process or crashing the MCP connection.
- **Tool Caching**:
  - Caches tools discovered during active sessions so that AI agents retain tool definitions even during temporary local server reboots.
- **Extended Restart Buffer**:
  - For local servers (`plugin` and `studiopro`), increased the retry budget to 18 attempts (~27 seconds window) during connection failures (`ECONNREFUSED`, `ETIMEDOUT`, `ECONNRESET`), giving the Mendix runtime sufficient time to complete its boot sequence before executing pending tool calls.

#### 2. Configuration & Setup Updates (config/mcp-studiopro.json, scripts/setup.js)
- Updated `StudioPro` server configuration in `config/mcp-studiopro.json` and `scripts/setup.js` to route via `node scripts/mta-proxy.js studiopro`.
- Enhanced `scripts/verify-setup.js` to support verifying `studiopro` mode when configured as the active model source.

#### 3. Documentation (README.md)
- Updated repository highlights and architecture descriptions to reflect the self-healing and restart-resilient capabilities of `scripts/mta-proxy.js`.

---

### Upgrading / Migration Notes
Workspaces configured to use Studio Pro MCP should update their `.vscode/mcp.json`, `.cursor/mcp.json`, or `.claude/settings.json` by re-running:
```bash
npm run setup
```
*(or `.\setup.ps1` on Windows)*

Select `[2] Studio Pro MCP` to apply the updated proxy configuration.
