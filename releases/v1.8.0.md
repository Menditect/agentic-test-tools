# Menditect Agent Workspace Template - Release Notes

## Version v1.8.0

> Released on: 2026-09-24

### Release Summary
Renamed repository and template from `agentic-test-tools` to `agentic-test-workspace` to clearly reflect its role as an agent workspace environment and eliminate confusion with MCP tools.

---

### Detailed Changes
- **Repository Rename:** Renamed the repository to `agentic-test-workspace` (`https://github.com/Menditect/agentic-test-workspace`).
- **Package Definition:** Updated `package.json` package name to `agentic-test-workspace`.
- **Documentation:** Updated all clone URLs, workspace directory paths, and monorepo runner examples in `README.md` and `docs/mta-config-reference.md`.
- **Agent Directives:** Aligned all agent instruction files (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`) to reference `agentic-test-workspace` in the Cloned Repository Immutability Rule and Public Reference Rule.
- **Scripts & Diagnostics:** Updated setup and verification log output to reflect `agentic-test-workspace`.

---

### Upgrading / Migration Notes
No breaking changes. Existing workspaces can continue using their current setup. If desired, update your local remote URL:
```bash
git remote set-url origin https://github.com/Menditect/agentic-test-workspace.git
```
