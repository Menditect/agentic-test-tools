# Menditect Agent Workspace Template - Release Notes

## Version v1.0.0

> Released on: 2026-09-07

### Release Summary
Initial release of the Menditect Agent Workspace Template. Provides a turnkey environment for AI agents (Cursor, Claude Code, GitHub Copilot / Codex, Antigravity / Gemini, Cline) to design, build, and execute automated tests using Menditect Test Automation (MTA).

---

### Key Features & Capabilities

- **Interactive Setup Wizard**:
  - Script (`scripts/setup.js`, `setup.ps1`) to configure endpoints and Mendix project paths in under 60 seconds.
  - Automatically discovers local `.mpr` project files.
  - Generates configuration files for `.env`, `mta_config.json`, `.vscode/mcp.json`, `.cursor/mcp.json`, and `.claude/settings.json`.

- **Resilient MCP Stdio-to-HTTP/SSE Proxy**:
  - Script (`scripts/mta-proxy.js`) bridges stdio communication to HTTP/SSE MCP endpoints.
  - Automatically handles Mendix application restarts by buffering and retrying requests without crashing the AI agent.
  - Emits descriptive diagnostic error messages when endpoints are offline.

- **Granular Upstream Synchronization**:
  - Direct synchronization script for Menditect skills (`npm run update:skills`, `update-skills.ps1`) from `Menditect/agentic-test-skills`.
  - Direct binary updater for `mxcli` (`npm run update:mxcli`, `update-mxcli.ps1`) from `mendixlabs/mxcli`.
  - Unified updater (`npm run update`, `update.ps1`) to refresh all external assets.
  - Avoids git submodule merge conflicts in customer templates.

- **Multi-User Collaboration Guardrails**:
  - Pre-configured `.gitignore` excluding local configuration, downloaded binaries, and AI agent session/cache states.
  - Ensures clean team collaboration across shared repositories.

- **Universal Agent Directives**:
  - Standardized agent rulebooks (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`) instructing agents on tool selection and skills workflow.

- **Verification Tooling**:
  - Built-in verification script (`npm run verify`, `scripts/verify-setup.js`) to test MCP server responsiveness.
