# Menditect Agent Workspace Template - Release Notes

## Version v1.6.0

> Released on: 2026-09-15

### Release Summary
updated mta_config contract for playwright trace viewer

---

### Detailed Changes
- **Playwright Trace Viewer & Tracefile URL Configuration (`v1.6.0` Contract)**:
  - Canonical `mta_config.schema.json` updated to version `1.6.0`, introducing `playwright_viewer_url` (defaults to `"https://trace.playwright.dev/?trace="`) and `tracefile_base_url` (e.g. `"http://localhost:8081/rest/private/tracefile?fileUUID="` or dynamically derived from `mta_base_url`).
  - Added optional instance-level `tracefileUrl` property to `app_instances[]`.
  - Added backward-compatible defensive aliasing (`playwrightViewerUrl`, `tracefileBaseUrl`, `tracefile_url`) in `scripts/setup.js`.
- **Interactive Trace Inspection in Execution & Diagnostics (`PAT-90`)**:
  - `mta-run-analyze` automatically detects the `FileUUID` property in `GetTestRunResults` (`GetTestCaseRunDetails`) for recorded Playwright trace artifacts.
  - Assembles and renders direct clickable Playwright Trace Viewer links (`[Open Trace in Playwright Viewer](...)`) in execution reports and diagnostic receipts for instant visual debugging of browser actions, network requests, and DOM snapshots.
- **Interactive Setup & Diagnostics (`npm run setup`, `npm run verify`)**:
  - `scripts/setup.js` initializes `playwright_viewer_url` and `tracefile_base_url` automatically during guided setup.
  - `scripts/verify-setup.js` adds `checkPlaywrightTraceSettings()` to inspect and report Playwright trace inspection readiness.
- **Contract & Documentation Alignment**:
  - Aligned `README.md` and `docs/mta-config-reference.md` with canonical contract v1.6.0 and resolution hierarchy rules.

---

### Upgrading / Migration Notes
No breaking changes. Workspaces upgrading to v1.6.0 can optionally specify `playwright_viewer_url` and `tracefile_base_url` in `mta_config.json` or `.env` (`PLAYWRIGHT_VIEWER_URL`, `MTA_TRACEFILE_BASE_URL`). If omitted, `playwright_viewer_url` defaults to `https://trace.playwright.dev/?trace=` and `tracefile_base_url` dynamically resolves to `${mta_base_url}/rest/private/tracefile?fileUUID=`. Run `npm run verify` to check configuration readiness.
