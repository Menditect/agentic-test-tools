# Menditect Agent Workspace Template - Release Notes

## Version v1.0.1

> Released on: 2026-09-07

### Release Summary
Improved the settings for mxcli and workspace environment resolution.

---

### Detailed Changes

- **Automatic `.vscode/settings.json` Generation**:
  - The setup script (`scripts/setup.js`) now creates `.vscode/settings.json` during workspace initialization.
  - Automatically maps `MENDIX_PROJECT_PATH`, `MENDIX_MPR_FILE`, and `MTA_BASE_URL` into terminal environment variables across Windows, macOS, and Linux configurations.
  - Eliminates configuration notices emitted by AI agents that cross-reference VS Code environment settings.

- **Multi-User Collaboration Safeguards**:
  - Added `.vscode/settings.json` to `.gitignore` so that developer-specific local paths are not committed to shared team repositories.

- **Repository Governance & Cleanups**:
  - Added `.github/CODEOWNERS` to designate ownership and change review authority to Menditect administrators.
  - Added `CONTRIBUTING.md` outlining repository contribution guidelines.
  - Updated repository remote and documentation URLs to the official Menditect organization (`https://github.com/Menditect/agentic-test-tools`).

---

### Upgrading / Migration Notes
Existing workspaces can re-run `npm run setup` to automatically generate `.vscode/settings.json` with their configured Mendix project path. No breaking changes.
