# Menditect Agent Workspace Template - Release Notes

## Version v1.1.1

> Released on: 2026-09-08

### Release Summary
Added Bearer token authentication to the interactive setup script for both MTA MCP and MTA Plugin MCP, including automatic token normalization, persistent configuration across mta_config.json, .env, and .vscode/settings.json, enhanced proxy error diagnostics, and pre-flight verification checks.

---

### Detailed Changes

#### 1. Interactive Setup Wizard Updates (scripts/setup.js)
- **MTA Bearer Token Prompt**:
  - The setup script now prompts for the required MTA Bearer token during workspace initialization.
  - Automatically loads and pre-fills existing configuration when running setup on an existing project.
- **App Under Test Plugin Token**:
  - Prompts for the plugin authentication token, defaulting to `Bearer 1` for local test instances.
- **Automatic Token Normalization**:
  - Added `formatBearerToken` utility to ensure all entered tokens comply with RFC 6750 by automatically prepending `Bearer ` if only the raw token string is pasted.
- **Persistence Across Workspace Configs**:
  - Saves `mta_auth_header` and `plugin_mcp_token` to `mta_config.json`.
  - Sets `MTA_MCP_AUTH_HEADER` and `PLUGIN_MCP_TOKEN` in `.env`.
  - Injects `MTA_MCP_AUTH_HEADER` and `PLUGIN_MCP_TOKEN` into `.vscode/settings.json` terminal environments across Windows, Linux, and macOS profiles.

#### 2. MCP Proxy Engine Authentication (scripts/mta-proxy.js)
- **Direct mta_config.json Resolution**:
  - The MTA proxy now checks `config.mta_auth_header` directly from `mta_config.json`, in addition to environment variables (`MTA_MCP_AUTH_HEADER` / `MTA_MCP_TOKEN`).
  - Emits an immediate warning if no authentication token is configured for MTA MCP requests.
- **Actionable Authentication Failure Diagnostics**:
  - Intercepts HTTP 401 Unauthorized and 403 Forbidden responses from upstream servers and provides clear diagnostics directing users to verify their Bearer token in `mta_config.json` or `.env`.

#### 3. Setup Verification Enhancements (scripts/verify-setup.js)
- **Pre-flight Token Inspection**:
  - Checks for the presence of Bearer tokens before attempting socket connections to MCP endpoints.
  - Emits explicit warnings when tokens are missing or unconfigured.
  - Distinctly highlights authentication failures versus general network/timeout issues.

#### 4. Documentation (README.md)
- Updated prerequisites to explicitly list the MTA Bearer token requirement.
- Updated Step 2 setup wizard walkthrough with token prompt explanations.

---

### Upgrading / Migration Notes
Existing workspaces running on prior releases should update by running:
```bash
npm run setup
```
*(or `.\setup.ps1` on Windows)*

Enter your MTA Bearer token when prompted. The wizard will automatically format the header and update your local configuration files.
