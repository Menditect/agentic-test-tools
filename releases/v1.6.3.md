# Menditect Agent Workspace Template - Release Notes

## Version v1.6.3

> Released on: 2026-09-16

### Release Summary
improved verification of mcp servers

---

### Detailed Changes
- **Fixed Multiline JSON Response Parsing in Proxy & Verification Scripts**:
  - Fixed `mta-proxy.js` stdout output to properly format entire JSON responses as single newline-delimited JSON-RPC messages rather than splitting formatted multiline JSON objects into unparseable line fragments.
  - Enhanced `verify-setup.js` response evaluation to handle both entire buffered payloads and line-by-line JSON-RPC streams, eliminating false timeouts when receiving multiline error or response payloads.
  - Enabled session auto-healing and error retry across all modes in `mta-proxy.js`.
- **Extended Preflight Verification Timeouts for Cloud MCP Endpoints**:
  - Increased `verify-setup.js` verification timeout to 25 seconds for the `mta` cloud MCP server and 10 seconds for local endpoints (`plugin`, `studiopro`), preventing false-positive timeouts during remote TLS handshakes, container wake-ups, or remote token authorization.
  - Added actionable troubleshooting hints upon verification timeout guiding users to check network connectivity and verify `MTA_MCP_AUTH_HEADER` in `.env`.
- **Increased HTTP Socket Timeout in MTA Proxy**:
  - Adjusted `sendHttp` timeout in `scripts/mta-proxy.js` to 25 seconds for `mta` mode, ensuring long-running cloud queries and schema discoveries complete reliably without socket drops.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run verify` to test MCP server connectivity with the improved parsing and timeout thresholds.
