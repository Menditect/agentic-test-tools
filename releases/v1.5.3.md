# Menditect Agent Workspace Template - Release Notes

## Version v1.5.3

> Released on: 2026-09-15

### Release Summary
automatic syncing of skills at setup

---

### Detailed Changes
- **Automatic Skills Synchronization on Setup**:
  - `npm run setup` (and `.\setup.ps1`) now automatically pulls the official Menditect Agentic Test Skills from `Menditect/agentic-test-skills` directly into the designated `skills_dir` upon saving configuration.
  - Automatically aligns and synchronizes the canonical `mta_config.schema.json` contract from upstream references into the workspace.
  - Eliminates the previous requirement to run `npm run update` immediately after a fresh setup before the agent can design or run tests.
  - Includes resilient non-blocking error handling: if internet access or Git is unavailable, setup displays a clear warning and continues configuring `.env`, IDE settings, and runners without crashing.
- **CLI Flags & PowerShell Parameter Forwarding**:
  - Added `--skip-skills` (along with `--no-skills` and `--skip-skills-sync`) to `scripts/setup.js` for CI environments or offline installations.
  - Updated `setup.ps1` to forward all parameters (`@args`) to `scripts/setup.js`, enabling commands like `.\setup.ps1 --skip-skills` and `.\setup.ps1 --directives-only`.
- **Diagnostic Verification of Skills Presence**:
  - Enhanced `scripts/verify-setup.js` with `checkSkillsPresence()` to audit whether `AGENTS.md` and core MTA domain skills (`mta-test-design`, `mta-build`, `mta-run-analyze`, `mta-install-config`) are present and complete.
- **Documentation & Reference Updates**:
  - Updated `README.md` and `docs/mta-config-reference.md` to reflect that skills are synchronized on setup and clarified that `npm run update` is for periodic maintenance.

---

### Upgrading / Migration Notes
No breaking changes. Existing workspaces can continue using their current configuration. Running `npm run verify` will now also verify the presence and completeness of your local MTA skills.
