# Menditect Agent Workspace Template - Release Notes

## Version v1.8.1

> Released on: 2026-09-25

### Release Summary
dynamic configuration of mcp servers and tokens in mta_proxy

---

### Detailed Changes
- **Dynamic Per-Request Hot-Reloading in `mta-proxy.js`**: Re-evaluates configuration and `.env` / `.env.local` before each incoming JSON-RPC request. Updated bearer tokens are picked up immediately on the next tool call without restarting the proxy process or reloading the IDE window.
- **Smart Secret Precedence & Upward Discovery**: Environment secrets always take precedence over static startup CLI arguments. Multi-path discovery locates `.env` across `MTA_CONFIG_PATH`, working directories, and upward parent directories.
- **MCP Subprocess Protection Directive**: Added strict instructions in `AGENTS.md`, `GEMINI.md`, and `CLAUDE.md` prohibiting agents from executing terminal commands (`Stop-Process`, `taskkill`, `kill`) against running MCP server processes, preventing permanent stdio pipe breakage in AI IDEs.
- **Sanitized IDE & Global MCP Configuration**: Enhanced `setup.js` to configure MCP server definitions across VS Code, Cursor, Claude Code, Antigravity (`mcp_config.json`), and Claude Desktop cleanly without embedding tokens into arguments, injecting `MTA_CONFIG_PATH` via `env`.
- **Expanded Security Hygiene in `verify-setup.js`**: Added automated scanning of IDE and global MCP configurations for hardcoded credentials or obsolete proxy paths, along with actionable recovery guidance for HTTP 401 authentication failures.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run verify` to inspect your workspace configuration and ensure IDE MCP definitions are sanitized.
