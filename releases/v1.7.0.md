# Menditect Agent Workspace Template - Release Notes

## Version v1.7.0

> Released on: 2026-09-17

### Release Summary
improved setup and diagnostics

---

### Detailed Changes
- **Streamlined Application Instance Discovery & Configuration in Setup**:
  - `scripts/setup.js` now automatically imports and configures all discovered MTA Application Instance Tokens found across Mendix project configurations in `.mpr`.
  - Removed redundant intermediate prompt asking users to filter instances, presenting a single clean prompt to select the active default instance for `ExecuteTest`.
  - Pre-selects the existing default instance from `mta_config.json` by default, enabling one-press Enter confirmation during re-configuration.
  - Automatically selects single discovered instances without prompting.
- **Accurate and Honest MCP Server Diagnostics**:
  - Enhanced `scripts/mta-proxy.js` to disable mock fallback schemas when running in verification mode (`MCP_VERIFY_MODE=true`).
  - Updated `scripts/verify-setup.js` to probe live HTTP endpoints directly and distinguish between:
    - **Plugin MCP Server**: Reports `[NOTICE] Plugin MCP Server is offline` when the local Mendix application is stopped, rather than falsely reporting a successful response from mock schemas.
    - **Cloud MTA MCP Server**: Directly tests live endpoint connectivity and surfaces explicit authentication errors when tokens in `.env` require updating.
    - **Studio Pro MCP Server**: Validates live accessibility on port 7782 when configured as the active model source.
- **Preserved Upstream SSOT Alignment**:
  - Maintained complete separation between `agentic-test-tools` template versioning and upstream `agentic-test-skills` schema contracts (`references/mta_config.schema.json`).

---

### Upgrading / Migration Notes
No breaking changes. Re-run `npm run setup` for the streamlined interactive experience or `npm run verify` for authentic, real-time MCP server diagnostics.
