# Menditect Agent Workspace Template - Release Notes

## Version v1.3.0

> Released on: 2026-09-10

### Release Summary
Discovery for app instances in mpr file added. Introduces automated Mendix model discovery of Menditect Test Automation (MTA) application instance tokens and connection parameters via `mxcli describe settings Settings`, support for multiple application instances (e.g. local, test, acceptance, cloud), active default instance designation for `ExecuteTest`, automatic injection of instance mappings into agent directives and environment variables, and preflight configuration drift detection against the Mendix project model.

---

### Detailed Changes

#### 1. Automated Model Settings & Instance Discovery via mxcli (scripts/setup.js)
- **Direct Model Inspection**:
  - The setup wizard now automatically invokes `mxcli describe settings Settings -p <mpr>` to inspect configuration constants defined across all Mendix Studio Pro configurations.
- **Extracted Model Constants**:
  - `MtaPluginModule.ApplicationInstanceToken`: Identifies all configured application instances across Studio Pro configurations (such as `local`, `test`, `cloud`, or team-specific profiles).
  - `MtaPluginModule.MTAConnectionUrl`: Automatically extracts and translates WebSocket connection URLs (`wss://...`) to HTTPS base URLs (`https://...`).
  - `MtaPluginModule.McpServerAccessToken`: Automatically extracts the plugin Bearer token (`Bearer 1`).
  - `HttpPortNumber`: Automatically detects the local runtime port (e.g. `8081`) and pre-configures the plugin MCP endpoint (`http://localhost:<port>/plugin/mcp`).
- **Interactive Review & 1-Click Confirmation**:
  - When instances are discovered, the setup wizard prints a structured summary displaying each configuration name alongside a masked token preview (`e8d2336f...c700`).
  - Allows confirming all discovered instances with a single keystroke.
  - Interactively prompts to select which instance serves as the active default for test execution.

#### 2. Multi-Instance Configuration & Manual Fallback (scripts/setup.js)
- **Interactive Multi-Instance Fallback**:
  - If no instances are defined in the Mendix model settings (or if the user opts for manual configuration), the wizard prompts for the total number of instances (minimum 1).
  - Collects a friendly name (e.g. `local`, `test`, `acceptance`) and the corresponding UUID token provided by the MTA Portal (Application > Application Instances) for each instance.
  - Enforces non-empty token input and validates standard UUID format.
- **Active Default Instance Selection**:
  - When more than one instance is configured, prompts the user to select the default instance to be used by autonomous AI test agents.

#### 3. Configuration & Environment Persistence
- **mta_config.json**:
  - Stores the full `app_instances` array containing each `{ name, token }` pair.
  - Stores `default_app_instance` and `default_app_instance_token`.
- **.env**:
  - Exports `MTA_APP_INSTANCE_TOKEN`: The active default instance token required by MTA MCP's `ExecuteTest` tool.
  - Exports `MTA_APP_INSTANCE_DEFAULT`: The active default instance name.
  - Exports sanitized per-instance variables: `MTA_APP_INSTANCE_<NAME>` (e.g. `MTA_APP_INSTANCE_LOCAL="<uuid>"`).
- **.vscode/settings.json**:
  - Automatically injects `MTA_APP_INSTANCE_TOKEN` into `terminal.integrated.env.*` for Windows, Linux, and macOS environments.

#### 4. Agent Directives Injection
- **AGENTS.md, CLAUDE.md, GEMINI.md, and .github/copilot-instructions.md**:
  - The Menditect Architecture Setup block dynamically includes the full list of available application instances with their tokens and designates the active default:
    ```markdown
    # Menditect Architecture Setup
    - **CRITICAL OPERATIONAL COMMAND:** Always execute tasks using the core rules defined in: [skills/AGENTS.md].
    - **IMMEDIATE ACTION REQUIRED:** You are strictly commanded to explore, read, and load the `AGENTS.md` and context of the `skills/` directory before answering any user prompt.
    - ** Application name is: [Menditect_CarRental_Insurance] **
    - ** MTA Url: [https://mta-trial.mendixcloud.com] **
    - ** Application Instances for ExecuteTest: **
      - [local] (Default): `e8d2336f-2367-4830-af03-9b2b467bc700`
      - [test]: `d5c7c3b5-dbd8-4f7a-99ed-47d5e3cf7873`
    ```
  - Eliminates the need for AI agents to pause execution and prompt the user for an `ApplicationInstanceToken` when running `ExecuteTest`.

#### 5. Preflight Verification & Drift Detection (scripts/verify-setup.js)
- **Token Availability Check**:
  - Validates that at least one application instance token is configured in `mta_config.json` or `.env`.
- **Model Drift Detection**:
  - Automatically queries the active `.mpr` project settings via `mxcli` to verify whether the active token still matches a known configuration in the Mendix model.
  - Notifies the user if configuration drift is detected or if an external custom instance is active.

#### 6. Architecture & Script Improvements
- **Lazy Readline & Safe Imports**:
  - Refactored `scripts/setup.js` to initialize `readline` lazily on first prompt, ensuring that importing setup helper functions in unit tests or scripts does not hang the Node.js event loop.
  - Exported core utilities (`inspectMendixMtaSettings`, `getMenditectSetupBlock`, `formatBearerToken`, `findMpr`, `detectMendixVersion`, `isVersion1112OrHigher`) for automated testing.
- **Process Isolation**:
  - Isolated `mxcli` child process execution (`stdio: ['ignore', 'pipe', 'ignore']`) to prevent stdin handle collision on Windows platforms.

#### 7. Documentation Updates (README.md)
- Updated setup wizard documentation to detail automated `mxcli` model discovery, multi-instance configuration, and `ExecuteTest` token requirements.

---

### Upgrading / Migration Notes
To upgrade an existing workspace to v1.3.0:
```bash
git pull origin main
npm run setup
```
*(or `.\setup.ps1` on Windows)*

Run the setup wizard to automatically detect your configured application instances from your Mendix project `.mpr` file and generate the updated `.env` and agent directives.
