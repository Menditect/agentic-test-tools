# Menditect Agent Workspace Template - Release Notes

## Version v1.5.0

> Released on: 2026-09-14

### Release Summary
improved handling of secrets and mxcli init

---

### Detailed Changes

#### 1. Decoupled Secret Storage & Security Hygiene
- **Environment File Decoupling**: Sensitive authentication headers (`MTA_MCP_AUTH_HEADER`, `PLUGIN_MCP_TOKEN`) are no longer written to `mta_config.json`. They are now securely written to `.env` (with file mode `0o600`).
- **Automatic `.gitignore` Protection**: `scripts/setup.js` automatically verifies and injects `.env` and `.env.local` into `.gitignore` across the workspace and tools directory.
- **Sanitized IDE Configurations**: `.vscode/settings.json` no longer contains sensitive tokens in `terminal.integrated.env.*`.
- **Proxy `.env` Support**: `scripts/mta-proxy.js` now reads `.env` and `.env.local` directly using zero-dependency parsing, preserving seamless MCP server operation.
- **Schema Contract Alignment**: Deprecated `mta_auth_header` and `plugin_mcp_token` in `mta_config.schema.json` with contract version updated to `v1.4.0` in exact alignment with `mta-ai-assistant` (`agentic-test-skills`), while maintaining transparent backwards-compatible fallback.

#### 2. Automatic `mxcli init` Scaffolding & Lifecycle Integration
- **Setup Wizard Scaffolding**: `scripts/setup.js` executes `initializeMxcli()` before generating IDE configs and directives, provisioning:
  - `.ai-context/skills/`: 72+ Mendix AI skills for microflows, pages, domain models, OData, and validation.
  - `docs/brain/`: Architectural decision and requirements store (`mxcli brain init`).
  - `.mxcli/`: Local working queue for uncommitted agent decisions and logs (git-ignored).
- **Workspace Option Boundaries**:
  - **Option 1 (`clone_root`)**: Scaffolds `agentic-test-tools` locally, strictly preserving the **zero files modified in Mendix repo** guarantee. Interactively prompts if the user also wants to scaffold their external Mendix project repository (default: No).
  - **Option 2 (`mendix_project`)**: Runs `mxcli init` directly inside the Mendix project repository so the whole team shares skills, lint configs, and assistant permissions.
  - **Option 3 (`custom`)**: Scaffolds the specified custom directory.
- **Agent Rule & Directive Preservation**: Pre-existing custom agent headers (such as `# Agentic Test Workspace Orchestrator`) and `# Menditect Architecture Setup` directives are preserved across `mxcli init` runs.
- **Non-Destructive Skill Updates**: In `scripts/sync-upstream.js`, updating `mxcli` (`npm run update:mxcli` or `npm run update`) automatically runs `mxcli init "<dir>" --sync-skills` across active workspaces to refresh skills without altering custom prompt rules.
- **Preflight Diagnostics (`scripts/verify-setup.js`)**:
  - Audits presence of `.ai-context/skills/` and `.mxcli/`.
  - Audits secret hygiene in `.vscode/settings.json`, `.gitignore`, and `mta_config.json`.

---

### Upgrading / Migration Notes
- Existing users can run `npm run setup` to automatically migrate legacy tokens from `mta_config.json` into `.env`, sanitize `.vscode/settings.json`, and scaffold `.ai-context/skills/`.
- Run `npm run verify` to confirm security hygiene and MCP server connectivity.
