# Menditect Agent Workspace Template - Release Notes

## Version v1.7.1

> Released on: 2026-09-24

### Release Summary
Remove PowerShell scripts and improve documentation

---

### Detailed Changes
- **PowerShell Script Elimination & Native Batch Transition**:
  - Removed `setup.ps1`, `update.ps1`, and `mxcli.ps1` to exclusively propose standard cross-platform `npm` commands (`npm run setup`, `npm run update`, `npm run verify`).
  - Converted `mxcli.bat` to a 100% native Windows Batch script (`cmd.exe`) without any PowerShell dependency.
  - Removed PowerShell execution policy notes from `README.md` and streamlined all command references.
- **Setup Script Usability & Guidance Enhancements**:
  - Added an upfront tip clarifying that bracket values `[value]` represent pre-detected defaults that can be selected simply by pressing `[Enter]`.
  - Restructured Question 1 (Workspace Selection) to prominently highlight the primary advantages and use cases for Option 1 (Dedicated Tools Workspace / Parent) and Option 2 (Direct Mendix Project Workspace) at the top of each choice.
  - Added an explicit warning before MCP verification: *"Make sure your app under test is running in Studio Pro when verifying the MCP connection!"*
  - Added an interactive prompt at the conclusion of setup offering to immediately run `npm run verify`.
  - Added post-setup `mta_config.json` configuration display and quick-start instructions for opening the workspace in Cursor, VS Code / Copilot, Claude Code, and Antigravity / Gemini.
- **Verification Diagnostics**:
  - Added App Under Test running reminder to Plugin MCP server verification in `scripts/verify-setup.js`.
