# Menditect Agent Workspace Template - Release Notes

## Version v1.8.4

> Released on: 2026-09-25

### Release Summary
Align global Antigravity MCP paths and populate explicit environment variables in setup

---

### Detailed Changes
- **Antigravity Global Configuration Alignment**:
  - Updated `scripts/setup.js` to target the official Antigravity global configuration path (`~/.gemini/config/mcp_config.json`) alongside fallback directories (`.gemini/antigravity/` and `.gemini/antigravity-ide/`).
- **Explicit Environment Injection**:
  - Configures `MTA_MCP_AUTH_HEADER`, `PLUGIN_MCP_URL`, and `PLUGIN_MCP_TOKEN` directly in the Antigravity `env` block, preventing startup authentication failures from path or working directory mismatch.

---

### Upgrading / Migration Notes
Run `npm run setup` in your workspace to automatically update and synchronize your IDE MCP configuration files.
