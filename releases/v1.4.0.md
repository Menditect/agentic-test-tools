# Menditect Agent Workspace Template - Release Notes

## Version v1.4.0

> Released on: 2026-09-14

### Release Summary
Improved installation process and folder structure. Streamlined repository root level by eliminating obsolete templates, redundant documentation stubs, and single-purpose PowerShell wrappers. Upgraded the Windows update runner with parameter switches, added dynamic template version banners to all CLI scripts, and refined the interactive setup workflow.

---

### Detailed Changes

#### 1. Repository Structure & Root Optimization
- **Removed Obsolete Configuration Template**:
  - Deleted `mta_config.json.template` which lagged behind modern schema specifications.
- **Consolidated Documentation Directory (`docs/`)**:
  - Removed outdated and redundant stubs (`docs/AGENT_COMPATIBILITY.md`, `docs/GETTING_STARTED.md`, `docs/MODEL_SOURCE_GUIDE.md`) whose information is fully maintained within `README.md`.
  - Retained `docs/mta-config-reference.md` as the authoritative Single Source of Truth (SSOT) configuration reference.
- **Consolidated PowerShell Runners**:
  - Replaced single-purpose `update-skills.ps1` and `update-mxcli.ps1` with an upgraded, parameterized `update.ps1`:
    - `.\update.ps1` (default: updates both skills and mxcli binary)
    - `.\update.ps1 -Skills` (updates Menditect skills only)
    - `.\update.ps1 -Mxcli` (updates mxcli binary only)

#### 2. Dynamic Version Display in CLI Tooling
- Integrated dynamic template version resolution from `package.json` into:
  - `scripts/setup.js` (`npm run setup`, `.\setup.ps1`): Displays banner `Menditect Agent Workspace Setup (v1.4.0)`.
  - `scripts/verify-setup.js` (`npm run verify`): Displays banner `Menditect Workspace Verification (v1.4.0)`.
  - `scripts/sync-upstream.js` (`npm run update`, `.\update.ps1`): Displays banner `Menditect Workspace Update (v1.4.0)`.

#### 3. Documentation Alignment
- Updated `README.md` to reflect the clean root layout, parameterized PowerShell update commands, and refined directory tree.

---

### Upgrading / Migration Notes
To upgrade an existing workspace to v1.4.0:
```bash
git pull origin main
npm run setup
npm run verify
```
*(or `.\setup.ps1` followed by `npm run verify` on Windows)*
