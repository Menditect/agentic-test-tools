# Menditect Agent Workspace Template - Release Notes

## Version v1.8.3

> Released on: 2026-09-25

### Release Summary
Preserve exact token string formatting and prioritize active workspace environment in proxy

---

### Detailed Changes
- **Token String Formatting**:
  - Removed forced whitespace injection when formatting MTA identification tokens in `scripts/mta-proxy.js` and `scripts/setup.js`.
  - Preserves exact concatenated prefix format (`Bearer menditect_mta_identification_token<token_key>`).
- **Workspace Environment Precedence in Proxy**:
  - Enhanced candidate directory resolution in `scripts/mta-proxy.js` so that the configured workspace directory (`MTA_CONFIG_PATH`) has highest priority and its `.env` settings cannot be overwritten by tool root directories or ancestor paths.
- **Documentation & Template Updates**:
  - Updated `.env.template` with accurate syntax documentation and examples.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
