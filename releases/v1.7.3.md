# Menditect Agent Workspace Template - Release Notes

## Version v1.7.3

> Released on: 2026-09-24

### Release Summary
updated documentation and user workflow

---

### Detailed Changes

- **Setup Prompt Choice Feedback**:
  - The setup wizard now explicitly outputs the chosen value when accepting default options (e.g. `-> Selected: <value>`), making configuration choices clear in the terminal.
- **Streamlined Setup Completion Guidance & Reference**:
  - Replaced cluttered command output at the end of setup with standard Next Steps for all supported editors (Cursor, VS Code, Claude Code, Antigravity/Gemini).
  - Added a clean reference to `README.md` (both locally in the `agentic-test-tools` folder and online on GitHub) for full command options and workflows.
- **AI Agent Self-Configuration Prompt**:
  - Added a recommended prompt to both `README.md` and the setup completion output instructing AI assistants on how to self-configure their MCP connections using `mta_config.json` and `.env`.
- **Documentation Refinements**:
  - Updated IDE setup documentation in `README.md` to highlight Agent Self-Configuration vs Manual Configuration.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:skills` and `npm run update:mxcli` to ensure dependencies are current.
