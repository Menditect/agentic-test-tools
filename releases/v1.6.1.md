# Menditect Agent Workspace Template - Release Notes

## Version v1.6.1

> Released on: 2026-09-16

### Release Summary
improved updating of skills and mxcli

---

### Detailed Changes
- **Granular Multi-Level Version Inspection (`npm run update:check`)**:
  - Implemented version discovery comparing local installed components against remote upstream releases before applying changes.
  - Inspects `mxcli` binary locally (`bin/mxcli --version`) vs. latest GitHub release (`https://api.github.com/repos/mendixlabs/mxcli/releases/latest`).
  - Inspects root orchestrator (`AGENTS.md`) and all individual domain skills (`SKILL.md` files: `mta-test-design`, `mta-build`, `mta-run-analyze`, `mta-install-config`, `menditecttestabilityframework`, and dynamically discovered upstream skills) via YAML frontmatter version parsing.
- **Interactive Update Confirmation Gate & Side-by-Side Status Matrix**:
  - `npm run update`, `npm run update:skills`, and `npm run update:mxcli` render an aligned comparison table showing Local Version, Remote Version, and Status (`Up to date` vs `Update available`).
  - Prompts the user interactively (`Proceed with update? [Y/n]`) before wiping skill directories or downloading binaries.
  - Supports non-interactive / CI automation flags: `--check` / `-c` (dry-run inspection only), `--yes` / `-y` (auto-confirm if updates exist), and `--force` / `-f` (force re-sync/re-download).
- **PowerShell Wrapper Enhancements (`update.ps1`)**:
  - Added `-Check`, `-Yes`, and `-Force` parameter switches to `update.ps1` for native PowerShell integration.
- **Agent Orchestrator Protocols**:
  - Added the **Upstream Skills & Tools Update Protocol** to `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` requiring AI agents to present the version comparison table and seek explicit confirmation before updating skills or tools.
- **Documentation & Script Aliases**:
  - Added `"update:check"` script alias to `package.json`.
  - Added Upstream Synchronization & Version Inspection documentation to `README.md`.

---

### Upgrading / Migration Notes
No breaking changes. Run `npm run update:check` (or `.\update.ps1 -Check`) to inspect installed versions against upstream, and `npm run update` to interactively synchronize your workspace.
