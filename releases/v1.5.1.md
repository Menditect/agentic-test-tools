# Menditect Agent Workspace Template - Release Notes

## Version v1.5.1

> Released on: 2026-09-14

### Release Summary
improved initialization of mxcli

---

### Detailed Changes
- **Automated Mendix Project Catalog Generation (`catalog.db`)**:
  - Integrated `buildProjectCatalog()` into the setup wizard (`scripts/setup.js`) right after local `./mxcli` runners are deployed.
  - Automatically compiles the SQLite catalog database at `<MendixProjectDir>/.mxcli/catalog.db` to power MTA test analysis, code search, and caller/callee graphs.
- **Large-Project Performance Advisory & Warnings**:
  - Added advance warnings informing developers that extracting complete MDL source definitions (`REFRESH CATALOG SOURCE`) reads all document contents across the model and can take several minutes to an hour on large enterprise applications.
- **Flexible Setup Execution Options**:
  - In interactive setup, developers can choose between:
    - `Y` (default): Deep extraction with full MDL source definitions (`REFRESH CATALOG SOURCE FORCE;`).
    - `fast`: Fast structural extraction covering entities, microflows, pages, activities, widgets, and strings (`REFRESH CATALOG FULL FORCE;`).
    - `n`: Skip catalog build with clear instructions on how to run it later.
- **Live Output Streaming**:
  - Replaced silent synchronous execution with live process streaming via `spawn`, displaying real-time progress ticks (`✓ Entities...`, `✓ Activities...`, `✓ source...`) without artificial timeouts.
- **Catalog Diagnostic Verification**:
  - Enhanced `scripts/verify-setup.js` (`checkMxcliBinary`) to inspect the project catalog's presence, file size, and last modified date.
- **Agent Directives & Documentation**:
  - Documented catalog commands and large-model duration expectations in `README.md`, `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, and `.github/copilot-instructions.md`.

---

### Upgrading / Migration Notes
No breaking changes. Existing workspaces can generate or refresh their project catalog at any time by running:
```bash
./mxcli -c "REFRESH CATALOG SOURCE FORCE;"
```
*(or `./mxcli -c "REFRESH CATALOG FULL FORCE;"` for fast structural indexing)*
