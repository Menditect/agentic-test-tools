# Menditect Agent Workspace Template - Release Notes

## Version v1.5.2

> Released on: 2026-09-14

### Release Summary
changed mta_config required fields

---

### Detailed Changes
- **Expanded Required Fields in `mta_config.json`**:
  - Aligned workspace schema with canonical contract v1.5.0 from `agentic-test-skills`.
  - Added `application_name`, `execution_plans_dir`, and `mendix_project_dir` as strictly required properties in addition to `mta_base_url` and `mcp_endpoint`.
  - Eliminates ambiguity and ensures agents always know the target application, Mendix project location, and test plan destination without prompting.
- **Execution Plans Single Source of Truth & Archive Deprecation**:
  - Deprecated `execution_plans_archive_dir` in configuration schemas.
  - Active execution plans are maintained and updated in-place at `execution_plans_dir` (`EP_*.md`), with revisions and history tracked via Git and MTA server persistence (`SaveExecutionPlan`).
- **Complete Skills Replacement on Update (Orphan Prevention)**:
  - Updated `scripts/sync-upstream.js` (`syncSkills`) to purge the target skills directory before downloading and copying the latest release from `agentic-test-skills`.
  - Guarantees no orphaned, obsolete, or renamed skill files remain after upstream updates.
  - Added clear user warning during synchronization that inline edits to MTA skills are erased and custom skills should reside in separate folders.
- **Fast Directive Recovery (`npm run setup:directives`)**:
  - Added `--directives-only` mode to `scripts/setup.js` and a dedicated `npm run setup:directives` command in `package.json`.
  - Allows instant restoration of the `# Menditect Architecture Setup` connection block across `AGENTS.md`, `CLAUDE.md`, and `GEMINI.md` without running the full interactive setup wizard if an external `mxcli init` overwrote them.
- **Agent Directives Integrity Audit**:
  - Enhanced `scripts/verify-setup.js` with `checkAgentDirectives()` to detect missing or corrupted Menditect connection blocks in agent guideline files.
- **Documentation & Agent Guidelines Updates**:
  - Updated `README.md`, `docs/mta-config-reference.md`, `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, and `.github/copilot-instructions.md` with the Skills Immutability & Customization Rule and directive restore instructions.

---

### Upgrading / Migration Notes
Workspaces upgrading to v1.5.2 should verify their `mta_config.json` contains the newly required fields:
- `application_name`: The Mendix application name in MTA.
- `execution_plans_dir`: Path to the execution plans directory (e.g. `./menditect-output/execution-plans`).
- `mendix_project_dir`: Path to the target Mendix project folder.

Run `npm run verify` to confirm configuration schema compliance and directive integrity.
